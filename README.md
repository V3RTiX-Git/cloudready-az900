# CloudReady AZ-900 Exam Coach

**Practice with purpose. Prepare with confidence.**

CloudReady is a lightweight, browser-based study tool that helps aspiring cloud professionals practise concepts covered by the Microsoft Azure Fundamentals (AZ-900) certification. It brings practice questions, answer explanations, topic-focused quizzes, and personal progress tracking into one simple interface.

> **Project status:** Hackathon prototype  
> **Built for:** PLP Vibe Coding Hackathon  
> **Technology:** HTML, CSS, JavaScript, and browser local storage  
> **Deployment:** Static website, suitable for GitHub Pages

---

## 1. The problem

Cloud computing is an important skill area for people exploring technology careers, but learners need more than reading material to check their understanding. They need opportunities to practise, see why an answer is right or wrong, identify topics they should revisit, and monitor their learning over time.

Beginners can also find it difficult to know where to start or how to organise their practice. CloudReady aims to make self-directed AZ-900 revision more approachable by bringing these activities together in one accessible browser-based tool.

## 2. Who it is for

CloudReady is intended for:
- Students and recent graduates exploring cloud computing.
- Beginners preparing to study for the Microsoft Azure Fundamentals (AZ-900) certification.
- Self-directed learners who want a simple way to practise cloud concepts.
- Aspiring IT, infrastructure, networking, and cloud professionals building foundational knowledge.

The prototype is an independent learning aid. It is not a substitute for the official study guide, hands-on learning, or the official certification exam.

## 3. What we built

CloudReady provides an interactive practice experience with features such as:
- **Practice quizzes:** Answer original practice questions in an interactive quiz flow.
- **Answer explanations:** Review explanations to help understand concepts and learn from mistakes.
- **Topic-focused practice:** Explore subject areas and practise questions related to a selected topic or domain.
- **Results and review:** Review quiz performance and revisit missed questions where supported by the current app.
- **Progress tracking:** Keep track of practice activity and progress in the browser.
- **Readiness view:** Use practice performance as a reflection aid to identify topics that may need more revision.
- **Responsive interface:** Use the app in a modern desktop or mobile browser.

Feature availability reflects the current prototype. The readiness view is an informal practice indicator, not a prediction or guarantee of an official AZ-900 exam result.

## 4. The product and how it works

A learner opens CloudReady in a browser, starts a mixed or topic-focused practice session, answers questions, and reviews feedback. The learner can then use the results and progress views to decide what to study next.

The product focuses on a short learning loop:
1. **Practise** with questions.
2. **Understand** the answer and explanation.
3. **Review** missed or difficult concepts.
4. **Repeat** practice and observe progress over time.

CloudReady is designed to be lightweight and easy to access without creating an account.

## 6. Alternatives and competitors

Learners can already use resources such as:
- **Microsoft Learn and the official AZ-900 study guide** for official learning content and exam objectives.
- **Online practice-exam and quiz platforms** for question-based revision.
- **Video tutorials, study groups, and personal notes** for explanations and revision.

CloudReady does not aim to replace official Microsoft learning resources. Its current differentiator is a simple, focused practice interface that brings quizzes, explanations, topic exploration, and browser-based progress tracking together in one lightweight prototype.

A formal competitor analysis and feature-by-feature comparison have not yet been conducted.

## 7. Competitive advantage

The current strengths of CloudReady are:
- **Focused experience:** Designed specifically around beginner-friendly AZ-900 practice.
- **Low-friction access:** Runs in a browser without requiring an account for the current prototype.
- **Learning through feedback:** Encourages learners to review explanations rather than only see a score.
- **Local-first progress:** Practice progress is stored in the user's browser instead of requiring a user account or cloud database.
- **Fast, lightweight prototype:** Uses standard web technologies and can be hosted as a static site.

These are prototype-level advantages, not claims that CloudReady outperforms established learning platforms.

## 14. Technology and implementation

The project is a static web application built with:
- **HTML** for page structure.
- **CSS** for styling and responsive layout.
- **JavaScript** for quiz interactions and application behaviour.
- **Browser local storage** for locally saved practice progress.

The app does not require a backend server or database for its current local-first experience. Progress stored in a browser is not automatically synchronised across devices and may be lost if the browser's site data is cleared.

## 16. Deployment

CloudReady is designed to be hosted as a static website. One option is GitHub Pages:
1. Push the project files to a GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under build and deployment, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder if `index.html` is at the repository root.
5. Save the settings and wait for GitHub Pages to publish the site.
6. Open the published URL and test the app.

## 17. Testing checklist

Before submitting or sharing the prototype, manually check the following in a browser:
- The dashboard loads without visible errors.
- A practice quiz can be started.
- Answers can be selected and submitted.
- Feedback or explanations appear where expected.
- Quiz results are displayed and scores appear reasonable.
- Topic-focused practice opens the intended topic, if available.
- Missed-question review works, if available.
- Progress remains after refreshing the browser.
- Navigation works and the layout remains usable at a narrow screen width.
- The published GitHub Pages URL works in a private/incognito window.

This checklist is a manual test guide, not a claim that automated tests have been run.
